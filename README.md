# JARVIS-data

やること（`todo.md`）とアイデア（`ideas.md`）の置き場です。**このリポジトリが正本**で、PC の JARVIS は読む前に取ってきて、書いたら送ります。PC が落ちていても、スマホから見る・書く・直すことができます。

## スマホ（GitHub アプリ）で使う
1. GitHub アプリでこのリポジトリを開き、`todo.md` か `ideas.md` を開く
2. 右上の鉛筆（編集）で直して、「Commit changes」を押す
3. 次に PC の JARVIS に「やることは？」と聞くと、直したものが反映されている

## `todo.md` の書き方
```
- [ ] 内容（足した日: 2026-10-07、期限: 2026-10-20）
```
- 期限は任意（`、期限: YYYY-MM-DD` を付けない行でもよい）。期限があると近い順に先に出て、過ぎると「期限切れ」と出ます
- **完了は `[ ]` を `[x]` に変える**だけ。できれば行の最後に `（完了日: YYYY-MM-DD）` を足す。行は消さない

## `ideas.md` の書き方
```
- [未整理] #12 2026-10-07 10:03 〔記事〕アイデアの本文
```
- 状態は 未整理／採用／保留／見送り。番号は使い回さない（先頭の `<!-- 次の番号: N -->` が次の番号）
- スマホで足すときは、一番下に 1 行足して、番号は「次の番号」にして、その数を 1 つ増やす

## 注意
- 秘密情報（パスワード・APIキーなど）は書かない
- PC と同時に直して押し合いになっても、JARVIS が最新の中身でやり直すので、どちらの変更も残ります
